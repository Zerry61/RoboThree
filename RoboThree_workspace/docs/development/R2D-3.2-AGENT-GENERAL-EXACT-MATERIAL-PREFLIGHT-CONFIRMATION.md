## 2. Exact immutable material

R2D-3.2 必须逐字段构造以下 material，不允许通过 spread 合并 fixture、当前 Agent、Renderer DTO 或可变配置：

```json
{
  "schemaVersion": "v1alpha2",
  "agentDefinitionId": "agent.general",
  "managementClass": "system_builtin",
  "name": "RoboThree 通用助手",
  "identity": "你是 RoboThree 通用任务助手，帮助用户处理分析、写作、信息整理和当前能力允许的工作空间任务。",
  "goal": "准确理解用户目标，以尽量少的阻塞完成任务，并交付真实、清晰、可验证的结果。",
  "instructions": "- 优先解决用户当前问题。\n- 不预设行业角色或专业立场。\n- 只使用当前任务真实启用的 Skill、Tool 和参考资料。\n- 不编造未提供的能力、文件、来源或执行结果。",
  "modelRestriction": { "mode": "unrestricted" },
  "skillRestriction": { "mode": "unrestricted" },
  "toolRestriction": { "mode": "unrestricted" },
  "knowledgeRestriction": { "mode": "unrestricted" },
  "requiredModelCapabilities": {
    "inputModalities": ["text"],
    "outputModalities": ["text"],
    "supportsToolCalling": false,
    "supportsStreaming": false
  },
  "createdAt": "2026-08-26T00:00:00.000Z"
}
```

### 2.1 字节规则

1. 所有字符串使用上方 exact Unicode code points；实现不得做 trim、翻译、全半角替换或运行时模板重写；
2. `instructions` 行间只使用 LF (`U+000A`)，每行以 ASCII `-` + 单个空格开头；
3. `instructions` 无开头空行、无结尾换行、无尾随空格；
4. `requiredModelCapabilities` 的两个 `false` 表示 built-in Agent 本身不额外要求 Tool Calling/Streaming，
   不表示模型不支持；具体 Task/Tool 决策只能继续收窄实际模型候选；
5. `minimumContextWindow` 必须省略，不得写 `null`、`0` 或猜测值；
6. `createdAt` 是 code-owned release epoch，不在进程启动、安装、首次使用或重启时重新采样。

## 3. Revision / digest 冻结

必须复用 R2D-2 已实现并通过 QA 的唯一规则：

```text
parsedMaterial = AgentDefinitionRevisionV1Alpha2MaterialSchema.parse(exactMaterial)
digestEnvelope = {
  domain: "robothree.agent-definition-revision.v1alpha2\n",
  material: parsedMaterial
}
digest = sha256CanonicalJson(digestEnvelope)
revision = digest
```

对 §2 exact material 使用当前 frozen `canonicalJsonStringify` 计算，预期结果为：

```text
revision = digest = sha256:f846f63e9b0b7135df865a2de832f0605643eeb25919201e1285315a250078cc
```

R2D-3.2 conformance 必须独立重算并断言该 exact digest，不能把预期 digest 作为实现输入，也不能绕过 material
校验直接返回常量。

任何进入 material 的字符、字段或固定时间变化都必须产生新 revision/digest；不得覆盖本 revision。历史 Task
继续通过 exact revision 加载旧 material，不按当前 source 重编译。Stable `agentDefinitionId` 保持
`agent.general`，但 stable ID 不代表 revision 可以原地变化。

## 4. `system_builtin` 管理与运行边界

`agent.general` 必须同时满足：

- source 为独立 code-owned `BuiltInGeneralAgentSource`；
- 不进入普通 Admin Agent 列表、草稿、测试、审核或发布流程；
- 不存在 edit/delete/publish/owner rebind API；
- 不从数据库单行、Renderer、环境变量、配置文件或 fixture 推导正文；
- 无 default model，不绑定 `model.desktop-scripted`；
- 四类 `unrestricted` 只表示 Agent 不额外收窄，最终可用资源仍必须与 exact entitlement、Registry、Workspace、
  authorization、Tool policy 和 accepted request 做交集；
- 未显式选择 Skill/Knowledge 时 selection 仍为空，不因 `unrestricted` 自动加载全集；
- Tool 仍由 `TaskToolCandidatePolicy` 决定，Agent 文本不能授予 Tool；
- production enterprise entitlement 不可用时不得用 built-in Agent 绕过 fail-closed。
