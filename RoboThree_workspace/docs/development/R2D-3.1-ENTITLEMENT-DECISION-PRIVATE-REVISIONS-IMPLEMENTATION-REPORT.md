## 2. 实现结果

### 2.1 Entitlement Snapshot 与 Decision

- 新增 Core-private `TaskResourceEntitlementSnapshotV1`，只承载不可逆 subject binding、exact authority
  revision、Model/Skill/Tool/Knowledge portable exact refs、唯一稳定 ordinal 与 identity evidence；
- Model/Skill/Knowledge 每类最多 64，Tool 最多 128；ID、ordinal、稳定顺序、Model revision/digest 和
  `testIdentityUsed => !productionIdentityReady` 均由 strict schema 失败关闭；
- snapshot digest 使用独立 domain `robothree.task-resource-entitlement-snapshot.v1\n`，覆盖 authority、四类
  exact refs、stable ordinals、observedAt 与 identity evidence；
- 新增 `AgentResourceDecisionV1`，只保存 exact Agent、entitlement digest、Registry revision、模型选择来源与
  最终 Model/Skill/Tool/Knowledge refs；explicit 必须携带并 exact 匹配 requested Model，preference/fallback
  禁止伪造 requested ID；
- decision digest 使用独立 domain `robothree.agent-resource-decision.v1\n`；raw entitlement、owner、Credential、
  Endpoint、Provider private mapping、正文与 runtime-only material 均被 strict schema 排除。

### 2.2 Runtime Selection v1alpha3

- 新增 exact package subpath `@robothree/contracts/runtime-selection/v1alpha3`；不从 Contracts root 或
  runtime-selection root index 导出；
- v1alpha3 是独立 material，不继承 `agentDefaultModelId`，新增 entitlement/decision digests、
  `explicit | user_preference | stable_fallback` 来源、portable Skill/Knowledge refs 与 Reasoning lock；
- explicit requested Model、Model/Tool capability kind、lock ID/capability uniqueness、Reasoning lock 的 Task/
  Model exact binding 及 Reasoning identity 独立均由 cross-field validation 固定；
- selection digest 覆盖完整 v1alpha3 material；新 helper 先读取一次 schemaVersion，再单次 dispatch v1/v2/v3，
  corrupted v3 与 unknown version 均 fail-closed，不 fallback legacy。

### 2.3 coordination v1alpha4

- 新增 exact package subpath `@robothree/contracts/submit-turn-coordination/v1alpha4`，继续使用 public
  SubmitTurn v1alpha3 request surface；
- v1alpha4 resource plan 精确绑定 Runtime Selection digest、Entitlement/Decision digests、authorization
  selection/execution digests、Task bundle digest、Instruction Binding digest、Model/Tool capability lock IDs、
  separate Reasoning lock identity、durable acceptance revision 与 acceptance Receipt identity；
- v1alpha4 复用既有 `accepted -> message_appended -> task_committed -> completed` 状态语义，不新增状态机、
  persistence table 或 migration；
- 新 helper 对 v1～v4 只做一次 schemaVersion dispatch；损坏 v4 不 fallback v3。production persistence Port、
  Coordinator、InMemory/SQLite Adapter 本批均未拓宽。
