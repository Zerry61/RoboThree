## 2. 关键实现

- coordination envelope 写入既有 `submit_turn_records.record_json`，严格绑定 v1alpha4 record、accepted plan 与
  envelope digest；每次 transition/complete/loop marker 都保留 exact plan 并重算 digest；
- Task bundle binding envelope 写入既有 `task_submit_turn_bindings.binding_json`，同时承载 public
  `TaskSubmitTurnBinding` 与既有 `TaskInstructionBindingV1`；
- 首次 accept 固定读取 exact Agent、subject binding、Entitlement、Registry、Workspace/Auth、可选 Preference、
  Tool policy 与 Planner；accepted 后恢复只读 durable plan，不重读 current authority；
- SQLite 在一个既有 database transaction 中提交 Task、Checkpoint、Model/Tool locks、Runtime Selection
  v1alpha3、Authorization、ReasoningModeLock identity 与双 binding；
- InMemory Adapter 在 staged state 中完成写入与 strict reload，全部成功后单一 pointer swap；
- `task_committed` 后 strict reload 全 bundle并原子生成 Receipt + Delivery；completed durable 后才调用 Agent Loop；
- `acceptanceReceiptIdentity=submitTurnCommandId`，transport delivery 使用独立 `preallocatedDeliveryId`。
