### 4. FOR UPDATE / ON CONFLICT / revision / consume / conditional update 固定 SQL ✅

| Mapper XML | FOR UPDATE | ON CONFLICT |
| --- | --- | --- |
| AuthenticationMapper.xml | 5 处 | 6 处 |
| ConfigurationMapper.xml | 0 处 | 2 处 |

关键 SQL 覆盖：`FOR UPDATE`（identity digest 锁定、device 锁定、permission 锁定、enrollment grant 消费）、`ON CONFLICT`（identity digest 幂等、device key 幂等、device public key 幂等、enrollment grant 唯一、challenge 幂等、token issuance 唯一写、snapshot digest 幂等、active configuration 唯一性）。

`MyBatisPersistenceErrors` 将 affected-row count 映射为 `PersistenceConflictException`/`PersistenceIntegrityException`。所有关键判断在同一 SQL 条件内完成，非 select→if→update 拆分模式。

### 6. 真实 PostgreSQL 验证 Spring TX 与 MyBatis SqlSession 同一 Connection ✅

`MyBatisTransactionConformance` 使用 `MyBatisConnectionIdentityMapper` 的 `@Select("SELECT pg_backend_pid()")` 在事务内多处调用，验证：
- 同一事务内多次 `pg_backend_pid()` 返回相同值
- `FOR UPDATE` → conditional `UPDATE`/`INSERT` → `commit`/`rollback` 在同一连接完成
- 非事务场景下连接可能不同（符合预期）

`SpringCentralTransactionRunner` 使用 Spring `PlatformTransactionManager` + `PROPAGATION_REQUIRED`，MyBatis SqlSession 由 `mybatis-spring` 自动与 Spring 事务绑定。

### 7. 32 路 Token issuance 和 20 路 Enrollment replay ✅

`PostgreSqlMyBatisPersistenceIntegrationTest`（4 tests）和 `CentralPersistenceConformance` 覆盖并发单写者幂等和重放拒绝。既有 `Cgf11dPostgreSqlRecoveryConformance` 的并发门禁（32 路 token issuance、20 路 enrollment replay）在 MyBatis 变体上回归通过。

### 8. 命名故障点 / close/reopen / 同 digest 幂等 / 不同 digest conflict ✅

`Cgf11dPostgreSqlRecoveryConformance`（命名崩溃点恢复）在 MyBatis 变体上回归通过。`CentralPersistenceConformance` 覆盖：
- 相同 ID + 相同 digest → 幂等
- 相同 ID + 不同 digest → `PersistenceConflictException`
- 事务回滚后数据不变
- `close()` 后拒绝新操作

### 9. PostgreSQL UUID / TEXT[] TypeHandler 合法及非法边界 ✅

**PostgresUuidTypeHandler**：显式 `JdbcType.OTHER`，使用 `PreparedStatement.setObject()` / `ResultSet.getObject(column, UUID.class)`，不依赖 JDBC 驱动隐式转换。`@MappedTypes(UUID.class)` + `@MappedJdbcTypes(JdbcType.OTHER)`。

**PostgresTextArrayTypeHandler**：显式 `JdbcType.ARRAY`，`createArrayOf("text", ...)` → `setArray()`，读取时 `array.free()` 释放资源。`List.copyOf` 返回不可变列表。`@MappedJdbcTypes(JdbcType.ARRAY)`。

`CentralPersistenceConformance` 覆盖 UUID 主键、TEXT[] 权限数组和 null 数组边界。
