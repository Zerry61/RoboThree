| 关注点 | 结论 | 证据 |

| **风险源 revision** | ✅ | `DOCUMENT_TOOL_RISK_SOURCE_REVISION = "builtin.document-tools.dwo2.v1"`；write 静态声明 `routine_file + destructive_file` |
| **动态风险 facts** | ✅ | `create_new` → `operation=create` + `riskFactKinds=[routine_file]`；`overwrite_existing` → `operation=modify` + `riskFactKinds=[destructive_file]`（`documentToolFileOperation` + 动态 riskFactKinds，`create-desktop-private-runtime.ts:536-562`）；`ToolExecutionService` 支持声明全集内的动态风险子集，不改公共 Contracts |
| **确认前旧 SHA 绑定** | ✅ | `buildXlsxOverwriteConfirmationMaterial`：lstat 拒 symlink/非 file/`nlink>1`、realpath 包含性、size ≤ maxFileBytes、读旧 SHA 计算 `confirmedOldSha256` + `computeXlsxOverwriteRequestDigest`，放入 Core 私有 action payload（`create-desktop-private-runtime.ts:787-832`） |
