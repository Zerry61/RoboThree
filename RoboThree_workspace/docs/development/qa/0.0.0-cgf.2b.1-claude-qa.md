## 12 项独立 QA 逐条验证

### 1. 独立执行 Central online/offline + Workspace 完整门禁 ✅

167/0/0/0 x2 + 107/685。独立执行，未引用开发者报告。

### 2. 两套 Adapter 独立 Wire 实现，相同 provider-neutral Projection ✅

- `AnthropicCompatibleModelProviderAdapter`（独立：route `/v1/messages`、`x-api-key` auth、Anthropic SSE format）
- `OpenAiCompatibleModelProviderAdapter`（独立：route `/v1/chat/completions`、`Authorization: Bearer` auth、OpenAI SSE format）
- 两者共用 `ModelProviderAdapter` Port、`ProviderAdapterSupport` 和 `BoundedModelStreamSink`
- 两套 Stub 同一组中文 text delta/Tool Call fragment/usage/`tool_use` terminal → 归一为相同 `ModelProviderStreamEvent` 序列

### 3. Request digest / Protocol / Binding route / finish reason 失败关闭 ✅

- 出站前重新校验 SHA-256 request digest
- Binding protocol 与 Adapter protocol 不匹配 → typed error
- 未知 finish reason → 失败关闭

### 4. Split/multiple frame / CRLF/LF / Unicode / Tool fragment / Usage ✅

`BoundedSseEventReader` 覆盖：split frame 重组、multiple frame 顺序、CRLF/LF/CR 均合法、Unicode 中文、Tool Call fragment 跨 frame 累加、Usage 解析与去重。

### 5. Malformed/incomplete / wrong Content-Type / late event / 非法 UTF-8 ✅

- malformed JSON → typed Provider error
- wrong Content-Type → 拒绝
- completed 后迟到 delta → 不污染结果
- 非法 UTF-8 → 失败关闭

### 6. Redirect / 401/403 / 429 / 5xx / deadline / idle / cancel ✅

- redirect → `manual` 模式，自动失败关闭
- 401/403 → typed auth error
- 429 → 解析 retry hint（如有）
- 5xx → typed Provider unavailable
- request deadline → `timed_out`
- stream idle → 超时关闭
- cancel → 传播并关闭响应流

### 7. Request/header/frame/aggregate/event/Tool argument 上限 ✅

`BoundedModelStreamSink` 限制：事件数、单段 UTF-8 字节、累计字节、Usage 重复检测。`JdkModelAuthorizedHttpTransport` 限制：请求体、响应头数量与大小。`ProviderToolCallAccumulator` 限制：参数累计大小，terminal 前验证完整 JSON Object。

### 8. Allowlist / DNS 地址类别 / URI 规范化 / private/loopback 生产拒绝 ✅

`StrictModelOutboundEndpointPolicy`：HTTPS only、host allowlist、DNS 解析后逐地址检查类别（loopback/private/link-local/multicast/unspecified → 拒绝）、URI 规范化（禁止 userinfo/query/fragment）、test-only loopback 仅测试 Transport 允许。

### 9. Credential 明文仅在 Transport 瞬时出现 ✅

`JdkModelAuthorizedHttpTransport`：从 `ModelCredentialMaterialSource` 获取 `char[]`，注入认证 Header 后立即 `Arrays.fill(password, '\0')` 清零。Provider Adapter 和 Domain 不接触明文。日志/Trace 不记录 Authorization Header。

### 10. W3C trace 白名单 Header + CR/LF/伪造拒绝 ✅

出站自定义 Header 白名单：仅 `anthropic-version`、`traceparent`、`tracestate`。`traceparent` 格式严格校验（version-traceId-spanId-flags），含 CR/LF 拒绝。客户端自报 `X-RoboThree-Trace-Id` 不被传播。
