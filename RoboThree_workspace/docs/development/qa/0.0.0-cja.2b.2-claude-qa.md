### 2. 双节点是两个独立 PID、两个随机端口、两个独立 Hikari Pool ✅

阅读 `Alignment2b2DualNodeFoundationIntegrationTest` 源码（720 行）确认：

- **独立 PID**：`ClusterNode.start()` 使用 `ProcessBuilder` 启动独立 `java` 进程。`assertThat(nodeA.processId()).isNotEqualTo(nodeB.processId())`（行 79）
- **独立随机端口**：`availablePort()` 使用 `new ServerSocket(0)` 分配空闲端口。`assertThat(nodeA.port()).isNotEqualTo(nodeB.port())`（行 80）
- **独立 Hikari Pool**：`ClusterHarnessConfiguration` 中 `@Bean HikariDataSource clusterHarnessDataSource(Environment)` 使用 `ROBOTHREE_CLUSTER_NODE_ID` 环境变量命名连接池 `"robothree-cluster-" + nodeId`。两个 JVM 各自实例化，池名不同
- **无 Java 对象共享**：Node A 和 Node B 是独立 JVM 进程，不共享 `ApplicationContext`、Bean、`static` 字段或内存 Persistence

### 3. 两节点只共享同一个 PostgreSQL 和显式测试 Port，不共享 Java 对象 ✅

`NodeEnvironment` record（行 518-525）持有 `jdbcUrl/username/password/tokenKey/seedInstant/deviceKeyId/publicKey`。两个节点使用相同的 `environment` 对象启动，但仅用于注入环境变量。每个节点通过 `ClusterHarnessConfiguration` 各自创建独立的 `HikariDataSource`。节点间唯一的共享状态是 Testcontainers PostgreSQL 实例。
