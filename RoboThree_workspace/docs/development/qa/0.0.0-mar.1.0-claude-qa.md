## 二、静态核查（MAR-1.0 基础，全部通过）

| 关注点 | 结论 | 证据 |
| --- | --- | --- |
| **global catalog 不污染 Task Detail** | ✅ | `loadTaskDetail` 的 `artifacts` 仅来自 `projectArtifactIndexForTask`（task-scoped tool 产物）；manual artifact 走独立 `listArtifactCatalog`（global catalog，`sourceKind=workspace_file`）并支持 sourceKinds/includeDeleted/limit 过滤（`desktop-task-projection-service.ts:294,399-454`） |
| **无 synthetic taskId/sessionId** | ✅ | manual artifact 不进入 Task Detail，无伪造 taskId；sessionId 非身份；`sourceKind=workspace_file` |
| **pathless command/query** | ✅ | `RegisterWorkspaceArtifactCommandSchema` 仅 `type` + 标准 metadata；`ListArtifactsQuerySchema` 仅 `sourceKinds/includeDeleted/limit`；均 `.strict()` 拒绝 workspaceRoot/rootRealPath/fileSha256/workbook/html/sessionId/unsafe relativePath |
| **sourceDigest 无 mtime（MAR-0 P3-1 已解决）** | ✅ | `sourceId = sha256({workspaceGrantId, relativePath, registrationKind})`；`sourceDigest = sha256({fileSha256, byteSize, mediaType, registrationSchema})`——**不含 mtime、不含路径**，touch-only 不再产生假冲突；`artifactId = sha256({sourceKind, sourceId, sourceDigest})`（`desktop-task-projection-service.ts:1746-1763`） |
| **幂等 / conflict** | ✅ | 同相对路径同 sourceDigest → 幂等返回既有 artifact；同相对路径不同 sourceDigest → conflict；`ManualArtifactRegistrationPersistence`（InMemory + SQLite）支持 receipt replay |
| **SQLite v17** | ✅ | 新增 `manual_artifact_registrations` 表 + `created_at` 索引；`desktop_command_receipts.command_type` 扩展支持 `register_workspace_artifact` receipt |
| **metadata-only** | ✅ | `previewState = "unsupported"` + reason "Manual file preview is not implemented in MAR-1.0."；不解析/不预览/不进 Document Worker |
| **无越界** | ✅ | MAR 标识仅 Contracts/Core；Desktop/DW/Central 生产代码无 MAR 实现；无 Tool Registry / model-visible artifact tool 注册；Renderer 的 `workspaceGrantId` 命中为既有工作区选择状态（MAR-0 §4 允许）；根 `package.json`/`pnpm-lock.yaml`/根 `tsconfig.json` 未改 |
