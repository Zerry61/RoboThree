- CGF-2 Plan 状态：`CONFIRMED` ✅

### 2. OpenAPI 只有 GET/POST，四个 Model Operation 绑定精确 Schema ✅

- 全部 11 处 model-invocation 路由使用 GET/POST
- 零 PUT/PATCH/DELETE
- accept（POST）、status（GET）、cancel（POST）、events（GET）四操作

### 3. 公共状态只有七项，`unknown` 被拒绝 ✅

`model-invocation.schema.json` 枚举：`accepted / running / completed / failed / cancelled / timed_out / uncertain`，不含 `unknown`。`fixtures/invalid/model-invocation-status-unknown.json` 验证拒绝。

### 4. Audience / Permission 固定，Model/Config/Generation 精确 ✅

- `audience = enterprise-model-gateway`
- `requiredPermission = model.use`
- `modelId + revision + configGeneration` 必须精确匹配

### 5. 身份 / Credential / Token / Provider Endpoint / Lease 无法进入 Accept Request ✅

`fixtures/invalid/` 覆盖：`model-invocation-accept-credential-leak.json`、`model-invocation-accept-self-declared-identity.json`。Recovery 字段（lease/recovery control）在独立 schema，不与 accept request 共用。

### 6. Synthetic 与 User-Confirmed Admission 不可混用 ✅

- `fixtures/valid/model-invocation-accept-synthetic.json`：`admission = development_synthetic`
- `fixtures/valid/model-invocation-accept-user-confirmed.json`：`admission = user_confirmed`
- `fixtures/invalid/model-invocation-user-admission-missing-confirmation.json`：user admission 缺确认字段

### 7. Durable Event 必须有 Sequence/Cursor，Ephemeral Event 不得携带 ✅
