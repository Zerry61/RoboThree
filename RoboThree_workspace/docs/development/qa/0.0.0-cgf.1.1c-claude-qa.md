### 5. 错误 signature/issuer/audience/issuedAt/expiry/issuance fact → 全失败关闭

`RoboThreeAccessTokenValidator.validate()`：
- **signature** → `tokenCodec.decodeAndVerify()` 抛异常 → `access_token_invalid`
- **issuer** → `claims.issuer()` ≠ `policy.issuer()` → `access_token_invalid`
- **audience** → `claims.audience()` ≠ `policy.audience()` → `access_token_invalid`
- **issuedAt** → `claims.issuedAt().isAfter(now + allowedClockSkew)` → `access_token_invalid`
- **expiresAt** → `now.isBefore(claims.expiresAt())` 为 false → `access_token_expired`
- **issuance fact** → 持久化记录 `tokenDigest` / `enterpriseId` / `userId` / `deviceId` / `clientInstanceId` / `permissions` / `issuedAt` / `expiresAt` 全部精确匹配 → 不匹配 → `access_token_invalid`

`validatorRejectsTamperingWrongIssuerAudienceAndExpiry` 测试覆盖：签名篡改（最后字符翻转）、错误 issuer、错误 audience、过期 token——全部正确拒绝。

✅ **PASS** — 六维度校验全部失败关闭。

### 6. 缺少 `configuration.read` → 不签发 Token、不下发配置

`RoboThreeAccessTokenService`：
```java
private static final String REQUIRED_BOOTSTRAP_PERMISSION = "configuration.read";
```

`requirePermissions()` 强制要求 `configuration.read` 在用户权限集中且 enabled。缺失时返回 `permission_denied`，Challenge 不消费。

`RoboThreeAccessTokenValidator.requirePermission()` 额外在配置读取路径上再次验证 Token claims 含 `configuration.read`，缺失返回 `permission_denied`。

✅ **PASS** — `configuration.read` 是硬门槛，既控制 Token 签发也控制配置读取。

### 7. ETag 稳定 / 304 无正文 / 401 缺少 Bearer

`EnterpriseAccessTokenAndConfigurationControllerTest.protectsConfigurationAndReturnsBodylessNotModified()`：
- 首次 `GET /v1alpha1/configuration` + `Authorization: Bearer <token>` → **200 OK**，ETag 与预期一致，`Cache-Control: no-store`，响应体为精确 canonical JSON
- 再次请求 + `If-None-Match: <etag>` → **304 Not Modified**，ETag 不变，**响应体为空字符串**
- 无 `Authorization` header → **401 Unauthorized**，错误码 `access_token_invalid`

`EnterpriseConfigurationController` 对 Bearer token 进行严格校验（prefix `Bearer `、长度、无空白字符），不通过 → `access_token_invalid`。

✅ **PASS** — ETag 稳定 / 304 bodyless / 401 typed error。

### 8. 篡改 Snapshot/Package/file digest / ETag / Package reference → 失败关闭

`ConfigurationIntegrityVerifier`：
- **Snapshot digest**：解析文档后排除 `digest` 重新计算 canonical JSON digest，与声明 digest 比对 → 不匹配 → `configuration_integrity_failed`
- **ETag**：验证 `quotedEtag(digest)` 与 snapshot.etag() 一致 → 不匹配 → 失败关闭
- **Package digest**：排除 `packageDigest` 重新计算 → 不匹配 → 失败关闭
- **File content digest**：对每个 `files[]` 条目验证 `sha256(utf8Content)` 与 `contentDigest` 一致 → 不匹配 → 失败关闭
- **Package reference**：对 `agents[]` / `skills[]` 中的每个 reference，查询持久化 Package → 不存在或 kind/digest 不匹配 → 失败关闭

`configurationRequiresValidTokenAndFailsClosedOnStoredDigestDrift`：存储 digest 被破坏后，配置读取抛 `configuration_integrity_failed`。

✅ **PASS** — Snapshot / Package / file digest / ETag / Package reference 全链路完整性验证，任一失败关闭。

### 9. Trusted seed 缺引用 → Package 与 Snapshot 同事务回滚

✅ **PASS** — Trusted seed 保证引用完整性与事务原子性。
