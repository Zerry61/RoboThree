## 二、静态核查（核心关注点全部通过）

| 关注点 | 结论 | 证据 |
| --- | --- | --- |
| **preview 查询 schema 严格拒绝私有字段** | ✅ | `ArtifactPreviewQuerySchema` `.strict()`：仅 `artifactId`（regex `^artifact:[0-9a-f]{64}$`）+ `mode(text|markdown)` + `maxBytes(1..64KiB)` + 标准 query metadata；Renderer 无法提交 `workspaceRoot`/`relativePath`/`sessionId`/`schemaVersion`/workbook/preview server 字段（`query.ts:63-68`） |
| **Core 预览不读工作区文件** | ✅ | `projectArtifactTextPreview` 从 durable successful Document Tool Observation 生成 Text/Markdown；不打开文件、不启动 parser worker、无网络/shell/外部资源能力；`previewState !== "available"` 失败关闭（`artifact-preview-projection.ts:141-171`） |
| **预览内容有界** | ✅ | `boundUtf8` 按 `maxBytes` 限长 + `truncated`/`preview_truncated` 标记；Contracts `ArtifactTextPreviewProjectionSchema` 断言 `byteSize` 与实际 UTF-8 字节一致 |
| **Renderer 无 innerHTML/v-html/iframe/webview/fetch/file open** | ✅ | 静态扫描零命中；`artifact-preview-presentation.ts` 的 `sanitizePreviewText = stripDangerousTokens(stripMarkdownUrls(escapeRawHtml(NFC)))`：先转义 `& < >`（raw HTML 惰性），再丢弃 Markdown link/image URL，再移除 `on*` 事件处理器与 `javascript:`/`data:`/`file:`/裸 `http(s)` URL |
| **Markdown 受限 block renderer** | ✅ | `markdownBlocks` 解析为 heading/paragraph/list_item/code/table_row 结构（≤128 blocks），全部经 Vue `h()` 文本节点渲染，无 HTML 字符串注入面 |
| **IPC/HTTP/Preload 严格校验** | ✅ | `previewArtifact` 在 Preload/IPC Router/Main client 三层均经 `ArtifactPreviewQuerySchema.parse`；是 Desktop/Application IPC 能力，非 model-visible Tool，不注册 `artifact.preview` |
| **无越界** | ✅ | 无 `artifact.preview` Tool 注册（命中均为既有 `previewBytes`/`previewState` 字段）；无 APV-1C preview server / openPath / shell.open / CSP 实现；Document Worker src / Central / `pnpm-lock.yaml` / 根 `package.json` / 根 `tsconfig.json` 未改 |
