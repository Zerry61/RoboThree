### 2. Runtime Selection Contract / 默认模型 / 合法-非法 override ✅

**Contract**：`packages/contracts/src/runtime-selection/runtime-selection.ts` — strict `AgentDefinitionRevision`、`ModelDefinition`、`TaskRuntimeSelection` Schema。

**默认模型**：
- `RuntimeSelectionService`：无显式 override → `agent.defaultModelId` ✅
- 显式 override → `agent.allowModelOverride` 必须为 `true` ✅
- `allowModelOverride=false` 时 `requestedModelId` 被忽略 ✅

**合法/非法 override**：
- `ModelEligibilityEvaluator`：仅计算用户权限 ∩ enabled ∩ Credential 可用 ∩ callable ∩ 显式能力要求的交集 ✅
- 不评分、不排序、不自动选"最佳模型"、不静默 fallback ✅

### 3. Model/Tool Lock 精确引用 + selection digest ✅

**Lock 机制**：
- Model 与所有首次可见 Tool 复用 `TaskCapabilityLockService`（ADR-008） ✅
- `TaskRuntimeSelection` 只引用精确 Lock 摘要 ✅

**Persistence 验证**：
- InMemory：`existing.selectionDigest === selection.selectionDigest` ✅
- SQLite：`INSERT INTO task_runtime_selections (..., selection_digest, ...)` ✅
- 写入前验证 Task、Lock ID、Capability ID、Registry revision、canonical lock digest ✅
- 每 Task 唯一、同 digest 幂等回放、不同 digest → typed conflict ✅

### 4. Skill/Knowledge/Workspace 引用漂移失败关闭 ✅
