## 二、静态核查（核心关注点全部通过）

| 关注点 | 结论 | 证据 |
| --- | --- | --- |
| **revision 跟踪落地** | ✅ | `ArtifactLifecycleProjection` 新增 `revision`/`deleted`/`deletedAt`/`restoredAt`/`deletionReasonSummary`；默认 revision 0 / deleted false；delete/restore 均 `revision + 1`（上轮 P3 观察已解决） |
| **idempotent replay 先于 revision 校验** | ✅ | `#replayArtifactLifecycleCommand`：commandId 命中后校验 `commandType + requestDigest + artifactId` 全匹配 → `replayed`，任一不匹配 → `desktop.command_idempotency_conflict`；replay 之后才校验 expected revision → stale → `desktop.artifact_revision_conflict`（`desktop-task-projection-service.ts:374-545`） |
| **deleted 记录禁止文件生命周期动作** | ✅ | pin/dismiss（`setArtifactLifecycle`）→ `desktop.artifact_deleted`；text/HTML preview 首查 `#artifactDeleted` → `desktop.artifact_deleted`；open location / export / HTML preview 共用 `resolveArtifactFileSource` 的 deleted 检查；Renderer 已删除卡片不显示 Text/Markdown/HTML/Reveal/Export/Pin/Dismiss 动作 |
| **record tombstone 不碰源文件** | ✅ | delete 只写 lifecycle overlay（deleted/deletedAt/reasonSummary），无 delete/move/rename/overwrite/read 源文件逻辑；唯一生产 `unlink` 为 DWE-1 XLSX temp 清理（`xlsx-write.ts:751`，既有非本批） |
| **无越界** | ✅ | `trashItem`/`moveItemToTrash`/`sourceDeleted`/`delete_artifact_source`/`artifact.delete`/`tool.artifact.*` 全零命中；Renderer 删除确认文案显式"源文件不会被删除"（`main.ts:532`） |
| **Renderer 零敏感字段** | ✅ | delete/restore 命令仅 `artifactId` + `expectedArtifactRevision` + 可选 `reasonSummary`，strict 拒绝路径/workspace/workbook/HTML/session identity；Preload 无新增敏感字段 |
| **已删除隐藏/恢复** | ✅ | Artifact Panel 默认隐藏 deleted（`showDeletedArtifacts` toggle），已删除卡片仅 metadata + Restore 动作，restore 需 `deleted === true` 前置 |
