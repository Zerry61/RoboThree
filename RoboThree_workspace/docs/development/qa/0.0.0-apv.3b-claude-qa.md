| **postcondition uncertain** | ✅ | Trash 后 `sourcePathUnavailable(originalPath)`（原路径必须 ENOENT/ENOTDIR）；不成立 → `artifact.delete_uncertain` 手动关注、不 commit、不盲目重试（`desktop-ipc-router.ts:471-483`） |
| **显式确认** | ✅ | `normalizeConfirmation(confirmationText)` 必须等于 `DELETE <displayName>`，不匹配 → `artifact_delete_confirmation_mismatch`；Renderer 要求用户输入完整确认文本（`main.ts:595`） |
| **symlink / hardlink / 身份漂移拒绝** | ✅ | `resolveDeletableContainedFile`：lstat 拒绝 symlink / 非 file / `nlink>1`（hardlink）；`realpath` 包含性；`stat` 的 `dev/ino` 与 `lstat` 不一致 → `changed`（源在 resolve 与 trash 之间被替换）→ `artifact.source_changed` conflict |
| **sourceDeleted 不可 restore** | ✅ | Core restore 对 `sourceDeleted` 拒绝 `desktop.artifact_restore_unavailable`（`desktop-task-projection-service.ts:536-540`）；Renderer 显示 "Source moved to Trash" 且不提供 restore |
| **Renderer 零敏感字段** | ✅ | source delete 命令仅 `artifactId` + `expectedArtifactRevision` + `confirmationText`，strict 拒绝路径/workspace/workbook/session；Renderer 敏感字段扫描零命中 |
| **deleted 后禁止文件生命周期动作** | ✅ | `resolveArtifactFileSource` 检查 deleted → open/export/HTML preview 均阻断 |
| **无越界** | ✅ | 无 APV-3C / manual artifact registration / overwrite / OS Sandbox / formal installer 实现；无 `artifact.delete` / `tool.artifact.*` 注册；Document Worker src / Central / `pnpm-lock.yaml` / 根 `package.json` / 根 `tsconfig.json` 未改 |
