### 2.2 InMemory/SQLite 同一 Conformance ✅

Harness 使用 parameterized test：`InMemoryConversationPersistence` 与 `SQLiteConversationPersistence`（`:memory:` + 临时文件）共享同一套 Conformance 断言，包括：

- 原子追加 batch/disposition
- 幂等 replay
- CAS 推进
- 并发单写
- Transaction C 原子提交
- Effect identity 不可更换
- close/reopen 后一致

测试函数命名格式 `"${variant.name} ADR17-I1 conformance"`，确保两套 adapter 使用完全相同矩阵。

### 2.5 Tool Result 不得更换 effectAttemptId ✅

Schema 层强制：

- `effect_linked` 与 `result_committed` disposition 必须含 `effectAttemptId`
- `ready_to_dispatch` 等非 Effect disposition 禁止携带 `effectAttemptId`
- 跨状态 transitions 时 `effectAttemptId` 一旦设定不可更换

Harness 覆盖：`"rejects a Tool Result completion that changes the linked Effect identity"`。
