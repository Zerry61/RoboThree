## 二、静态核查（核心关注点全部通过）

| 关注点 | 结论 | 证据 |
| --- | --- | --- |
| **write 模型可见 schema 不泄漏 workspaceRoot/limits** | ✅ | `xlsxWriteToolInputSchema()` = `{relativePath, workbook, options}`（`document-tool-registry.ts:525-542`）；registry 测试显式断言不含 `workspaceRoot`/`limits`（L130-131）；context 测试断言模型可见 write 工具不含 workspaceRoot（L151） |
| **Effect 持久化不保存 workspaceRoot** | ✅ | action payload = `{workspaceGrantId, relativePath, workbook?, options, limits}`（`create-desktop-private-runtime.ts:492-498`）；modelPayload = `call.arguments` 无 workspaceRoot |
| **执行前 hydrator 注入 workspaceRoot** | ✅ | `hydrateDesktopDocumentToolAction` 执行前重读 grant 的 `rootRealPath` 注入（L556-583）；`ToolEffectExecutor` 支持 action hydrator（`tool-effect-executor.ts:57`） |
| **WorkspaceGrant create 授权** | ✅ | write 用 `operation=create`（L513/537/546），read 用 `operation=read`；`currentContext` 每次重读 grant，缺失/撤销 → `unavailableDocumentToolAuthorizationContext` 失败关闭 |
| **target_exists 不派发 Worker** | ✅ | `writeTargetExists` 仅对 `isSafeCorePrecheckXlsxPath` 的相对 `.xlsx` 路径预检；命中 → `document_worker.invalid_format` + `detailCode=target_exists`，不构造 invoke（`document-worker-tool-backend.ts:320-334`）；非法/越界路径返回 false 交 Worker 路径守卫失败关闭 |
| **requestDigest 由 Core 计算** | ✅ | `computeXlsxWriteRequestDigest(idempotencyKey, relativePath, normalizedWorkbook)`，不由模型提供；Worker `verifyRequestDigest` 双端一致 |
| **v1alpha2 私有协议透传** | ✅ | Core invoke 使用 `DOCUMENT_WORKER_PRIVATE_PROTOCOL_VERSION`；Worker terminal 帧兼容 v1alpha1/v1alpha2；read 工具语义不变 |
| **Observation preview 有界摘要** | ✅ | `xlsxWritePreview` 只输出相对路径/byteSize/sheetCount/cellCount/sha256/logicalWorkbookDigest/warnings，整体 4096 字节有界，无绝对 root 或 workbook 正文（`document-tool-context.ts:170-183`） |
| **readOnlyHint** | ✅ | write=`false`，三个 read=`true`（registry 测试 L46-47） |
| **默认 Agent 注册** | ✅ | `agent.general` toolReferences 映射全部 registry definitions（含 write）——DWE-2 预期注册行为；Desktop scripted provider 仍只生成 read 调用 |
