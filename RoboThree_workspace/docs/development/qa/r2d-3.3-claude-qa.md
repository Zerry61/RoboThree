## 三、发现

### P0 = 0，P1 = 0，P2 = 0，P3 = 2

**P3-1 — Central online/offline 首次跑命中环境偶发（非 R2D-3.3、非阻断）**

- **online**：首次 `check:central` 报 `MojoFailureException`，实为 tracing exporter `Failed to export spans … timeout`（OpenTelemetry observability 导出超时），404 tests 全 0 failure，复跑干净 `404/0/0/0/BUILD SUCCESS`。
- **offline**：首次 `check:central:offline` 报 `Alignment2b2DualNodeFoundationIntegrationTest.closesFailureRecoveryAndResourceMatrixAcrossDualJvms` → `Web server failed to start. Port 49853 was already in use`。`lsof -i :49853` 证实端口被本机 `Doubao`（豆包）应用占用，非残留 Java 进程。复跑干净 `404/0/0/0/BUILD SUCCESS`。
- **结论**：二者均为 Central 双 JVM 集群集成测试对端口/tracing 出口敏感的环境偶发，与既往 CGF-2B3.2 / dcf13c 同类；R2D-3.3 未触碰 Central 任何路径（`desktopAdminChanged=false`，git status 无 Central 变更），非本批缺陷、非阻断。

**P3-2 — Desktop v1alpha3 Receipt 的 `defaultModelId` 兼容投影暂留（非缺陷，留待后续批）**

- 见 §2.1 项 D。Runtime Selection v1alpha3 权威事实不含 Agent default，Desktop receipt 把 exact resolved Model ID 填入 legacy 必填字段以满足旧 schema 兼容。实现注释明确该投影语义，非缺陷。
- **建议**：留待 Desktop/Admin v2 consumption 批随 Desktop Contract 升级移除；本批不改冻结 Desktop Contract 是正确的边界决策。
