## 二、静态核查（核心关注点全部通过）

| 关注点 | 结论 | 证据 |
| --- | --- | --- |
| **source 来自 durable Task checkpoint** | ✅ | `projectArtifactIndexForTask` 遍历 `task.checkpoint.state.runs[].steps[]`，过滤 `observation.outcome === "succeeded"` + `isDocumentToolCapabilityId`（`artifact-preview-projection.ts:96-108`） |

| **泄漏边界** | ✅ | 相对路径经 `isSafeWorkspaceRelativePath` 守卫（null byte/反斜杠/绝对路径/drive/traversal 拒绝），不安全 → `previewState="blocked"` 且省略 relativePath（test 5）；displayName 160 标量上限；metadata 4KiB 有界（超限截断为 `{truncated, originalMetadataBytes}`，test 6）；测试断言序列化不含 workspaceRoot/workbook 内容/`do-not-leak`（test 1） |
| **APV-0 P3 修复落实** | ✅ | 计划 §4 L93 "sessionId is deliberately not part of Artifact identity"、§5 L156 约束、§9 修改范围 + 硬阻塞判据均已写入 |
