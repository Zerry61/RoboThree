> **re-QA 修订结论**：原 §三 P3-1（基线 `database.enableDefensive is not a function`）与 P3-2（dcf13c-stability 并发偶发）**两项均不再成立**。本次在 Node v24.13.0 下完整 `check` 279/279 files、1930/1930 tests、3 smoke 全 PASS，未观察到 dcf13c 偶发。

**修订理由（用户要求修正根因）**：

- `.node-version` 声明为 `24.13.0`；仓库与 12 个 sqlite persistence 文件**没有**任何代码缺陷；

- 在 Node 22.22.1 下，这些原生方法在 `DatabaseSync` 上**未提供**——这是 Node 版本差异，不是 schema-preflight 缺失；
- 原 P3-1 的根因判断（`schema-preflight.configureSqlite` 未挂载 `enableDefensive`）属于环境层归因错误；本 re-QA **明确不修改 `services/core/src/adapters/sqlite/schema-preflight.ts`**、**不增加 Node 22 fallback**、**不建立 SQLite repair 批次**。

- **结论**：
  - **不是**仓库基线缺陷；`.node-version` 一直声明 24.13.0，代码按声明编写；
  - **不是** R2D-3.2 缺陷；R2D-3.2 未触碰任何 sqlite persistence 文件或 `schema-preflight.ts`（git diff 仅 `task-tool-candidate-policy.ts` 类型导入改名）；
