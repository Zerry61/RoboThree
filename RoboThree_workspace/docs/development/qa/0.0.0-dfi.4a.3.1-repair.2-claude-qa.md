## 一、独立代码核查（主要证据，非复跑）

逐行读取实现，四类关键实现核实如下：

### 1.1 四阶段 timeout 与 typed cause

- [local-personal-openai-compatible-model-provider.ts:246-396](services/core/src/adapters/https/local-personal-openai-compatible-model-provider.ts#L246)
  的 `LocalPersonalProviderTimeoutController` 持有 `#overall` / `#connect` / `#firstProgress` /
  `#idle` 四个 `ScheduledTask`，状态机 `startConnect → connected → progress → terminal` 清晰；
- overall 初始 delay = `invocationDeadlineAt - clock.now()`（line 271），**落实 Revision 1.1 P2-1**
  （禁止 DNS 前重新起算 `now + overall`）；
- `#lockCause`（line 371-379）以 `this.#cause !== undefined` 实现 CAS，首个 winner 锁定，`#terminate`
  在销毁 socket 前写入 typed cause；`dispose()` 与 `terminal()` 统一清理四类 timer；
- `resolveLocalPersonalProviderFailure`（line 942-951）优先级正确：`lockedCause` → error → signal →
  `network_failure`；`terminationFailure`（line 963-971）与 `raceWithTermination`（line 973-1000）都
  以 `terminationCause` 为准，杜绝 late `ECONNRESET` 反向覆盖本地 timeout。

结论：四阶段 timeout 与 typed cause 真实实现，非 stubbing。

### 1.2 重启不延长 durable deadline

- [sqlite-local-personal-model-invocation-persistence.ts:242-257](services/core/src/adapters/sqlite/sqlite-local-personal-model-invocation-persistence.ts#L242)
  的 `loadInvocationTimeoutFact` 按 `authorityInvocationId` 读取 exact Timeout Fact；
- [durable-local-personal-model-provider.ts:117-118](services/core/src/application/durable-local-personal-model-provider.ts#L117)
  在加载时对无 Timeout Fact 的 legacy pending 调用 `#exhaust(link, "local_personal.timeout_fact_legacy_missing")`
  → `recovery_exhausted`，不补造 deadline；
- [durable-agent-loop-starter.ts:690-708](services/core/src/application/durable-agent-loop-starter.ts#L690)
  local_personal 分支用 `createModelInvocationTimeoutMaterial`（单次 `invocationStartedAt`），不重新采样。

结论：重启/重试读取原 fact，不重新获得 15 分钟。

### 1.3 migration 25 及 migration 1～24 零漂移

- [migrations.ts:1382-1416](services/core/src/adapters/sqlite/migrations.ts#L1382) 为 additive
  `local_personal_invocation_timeout_facts`（STRICT + FK 到 invocation_links），id=25 为最后一迁移
  （`LATEST_SQLITE_SCHEMA_VERSION` = 25）；
- CHECK 约束落实 drift 关闭：`invocation_deadline_at > invocation_started_at`、source enum、
  digest 格式、timeout 范围 120000～1800000；
- conformance 测试 `local-personal-model-migration.integration.test.ts` 验证 23→24→25 升级不重写历史。

结论：migration 25 additive，1～24 零改写。

### 1.4 Agent Loop / Compaction 回归
