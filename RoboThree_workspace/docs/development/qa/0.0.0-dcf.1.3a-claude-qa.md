## 20 项独立 QA 逐条验证

### 1. clean build 完整门禁 ✅

86 files / 543 tests PASS。专项 5 files / 18 tests PASS。

### 2. lifecycle 六态、无 `recovering` ✅

`CorePrivateSupervisor` 状态：`stopped / starting / ready / restarting / stopping / failed`。`recovering` 不进入 lifecycle 枚举，Projection rebuild 留在 reconnect controller ✅

### 3. 并发 start/stop 串行化 / 最多一个 active child ✅

多个 start/stop 复用同一操作。ready Core 的 stop 未完成时到达的 start 会等待旧实例完全退出后才创建替换实例。任意时刻最多一个 active child ✅

### 4. 首次启动失败消耗唯一自动 restart + 新 token ✅

`#maxUnexpectedRestarts = 1`（Alpha 固定值）。异常退出 → `restarting` → 新 token + 新 `runtimeInstanceId` ✅

### 5. ready 后异常退出 → restarting / runtimeInstance 改变 ✅

`CorePrivateSupervisor` 检测到 ready 后异常退出 → 进入 `restarting` → 替换 Core 生成新 `runtimeInstanceId` ✅

### 6. 连续第二次异常退出 → `failed` / 不形成 restart storm ✅

`#maxUnexpectedRestarts = 1`。第一次消耗 → 第二次 → `failed`。`RESTART_DELAY_MS = 150` 防止快速重启 ✅

### 7. `failed` 后 `start()` 失败关闭 / 只能重启 Desktop ✅

`if (this.#state === "failed") throw new Error("Local Core failed; restart the Desktop application")` ✅

### 8. Renderer 只收到冻结文案 + `runtime.unavailable` + `retryable=false` ✅

Main 在最终启动失败时创建安全 Desktop 壳。业务 IPC 返回不可重试 typed 错误及冻结中文文案 ✅

### 9. 受控 restart 不消耗 unexpected restart budget ✅

受控 restart primitive 可靠停止当前实例后启动替换实例。不携带企业 generation/PID/shell command/任意参数，不消耗自动失败额度 ✅

### 10. replacement Core 使用新 token + 新运行代 + 有效新连接 ✅

每个替换 Core 生成新的高熵 Bearer + 新 `runtimeInstanceId`。旧连接失效 ✅

### 11. 旧 Client/Bearer/SSE/运行代 delta 不再可用 ✅

`runtimeInstanceId` 变化 → 旧 Client、旧端口/token、旧 SSE 与旧运行代投影不被复用 ✅

### 12. 旧 Workspace selectionHandle 在 restart 后失败关闭 ✅

handle 在 Core stop/restart 时失效。同一 picker 操作固定使用同一 Core Client ✅

### 13. handle resolve/cancel/discard 后删除 / TTL ≤ 30s / 不入 SQLite ✅

`MAX_SELECTION_TTL_MS = 30_000`。`grep -rn "selectionHandle" services/core/src/adapters/sqlite` → **0 命中** ✅

### 14. 同一 SQLite Session/Message/Task/delivery 不丢不重复 ✅

Desktop restart 后使用同一 SQLite 恢复持久事实。Session close/reopen 保留 ✅

### 15. reconnect 运行代变化清理临时 Projection / failed|stopped 停止重连 ✅

`DesktopEventReconnectController` 在生命周期到达 `failed/stopped` 后停止重连。运行代变化先清理旧 Projection，再以 Snapshot/durable cursor 收敛 ✅

### 16. stop/restart 期间资源清理 ✅

child/listener/timer/IPC/loopback 端口在 stop/restart 期间回收 ✅

### 17. stderr 与失败诊断有界脱敏 ✅

`STDERR_LIMIT_BYTES` 有界收集。过滤 Bearer-like 值和本地路径。不将 token/完整路径/数据库细节返回 Renderer ✅

### 18. Kernel reducer 无修改 + 不导入 DCF-1.3A 类型 ✅

Kernel `CoreLifecycle` 接口是 KAF-0 通用生命周期抽象（start/stop/state），不导入 Electron/HTTP/SSE/child_process/supervisor/restart state/SQLite Adapter ✅
