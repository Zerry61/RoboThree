### 2. Commit 前退出 — 事务回滚 ✅

源码验证（`Alignment2b2DualNodeFoundationIntegrationTest` 行 192-205）：

```java
// Node A: halt inside transaction → PostgreSQL rolls back
ObjectNode beforeCommit = permissionRequest(true, 1, ...);
beforeCommit.put("permission", "agent.use");
invokeCrash(nodeA, "/cluster-harness/failures/permission-before-commit",
    beforeCommit, 73);
assertPermissionAbsent(nodeB, "agent.use"); // Node B: agent.use absent
```

`ClusterHarnessApplicationService.haltBeforePermissionCommit`（行 111-117）在 Spring 事务内写入后调用 `Runtime.getRuntime().halt(73)`。PostgreSQL 回滚事务，Node B 查询确认 `agent.use` 权限不存在。`invokeCrash` 验证：退出码 73、端口关闭。

### 3. Commit 后响应丢失 — 同内容幂等、不同内容 conflict ✅

源码验证（行 207-234）：

```java
// Node A: write commits, then JVM halts before HTTP response
ObjectNode afterCommit = permissionRequest(true, 1, ...);
afterCommit.put("permission", "skill.use");
invokeCrash(nodeA, "/cluster-harness/failures/permission-after-commit",
    afterCommit, 74);
// Node B reads committed fact
assertPermission(nodeB, "skill.use", true, 1);
// Same content replay → idempotent 200
assertThat(post(nodeB, "/cluster-harness/permissions", afterCommit).status())
        .isEqualTo(200);
// Different content replay → 409 permission_conflict
ObjectNode conflictingReplay = afterCommit.deepCopy();
conflictingReplay.put("enabled", false);
HttpResult conflict = post(nodeB, "/cluster-harness/permissions", conflictingReplay);
assertThat(conflict.status()).isEqualTo(409);
assertThat(conflict.json().path("code").asText()).isEqualTo("persistence.permission_conflict");
```

### 4. Challenge 消费中强制退出 — 只出现两种可信持久结果 ✅

源码验证（行 237-260）：

```java

            .isEqualTo("device_challenge_replayed");

```

### 10. 重复 JVM start/stop — 无跨轮资源泄漏 ✅

源码验证（行 348-369）：

```java
// 4 lifecycle cycles
for (int cycle = 0; cycle < 4; cycle += 1) {
    ClusterNode node = ClusterNode.start("resource-cycle-" + cycle, environment);
    long processId = node.processId();
    int port = node.port();
    assertResourceProjection(node, "robothree-cluster-resource-cycle-" + cycle);
    node.close();
    // PID dead
    assertThat(ProcessHandle.of(processId).map(ProcessHandle::isAlive).orElse(false))
            .isFalse();
    // No descendant processes alive
    assertThat(ProcessHandle.of(processId).stream()
            .flatMap(ProcessHandle::descendants)
            .filter(ProcessHandle::isAlive)).isEmpty();
    // Port closed
    assertThat(canConnect(port)).isFalse();
    // PostgreSQL sessions drained
    awaitClusterConnectionCount(dataSource, 0);
}
```
