- **Event Sequence**：`(invocationId, sequence)` 唯一约束，duplicate → conflict
- **Lease Fencing**：epoch CAS，旧 epoch → `persistence.lease_fencing_conflict`
- **Outbox**：同事务写入，audit 失败不反向改变 Invocation

- **32 路并发单写者**：accept 并发 → 唯一成功
- **PostgreSQL close/reopen**：连接关闭 → 拒绝；重连 → 恢复
