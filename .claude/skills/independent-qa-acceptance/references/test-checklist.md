# Test Checklist

验收执行时的可勾选清单。每一项都必须明确给出"通过 / 失败 / 未验证 / 环境阻塞 / 不适用"五种结论之一，禁止留空。

> 适用前提：所有"自动化"项必须附命令与执行证据；所有"人工"项必须附操作步骤与观察记录。
>
> 三档执行模型：
> - **基础门禁**（每次必跑）：A1–A6、L1–L8
> - **风险相关**（适用时必跑，否则 N/A）：B、C、D、E、F、G、H、I、J
> - **不适用**：与本次范围无关，标 N/A 并说明原因
>
> **扫描排除列表**（mtime 辅助线索与基础门禁扫描都要排除）：
> `node_modules/`、`dist/`、`build/`、`out/`、`qa-reports/`、`.claude/`、`robothree-agent-research/sources/**`、`.git/`、`coverage/`、`.cache/`、`.next/`、`__pycache__/`
