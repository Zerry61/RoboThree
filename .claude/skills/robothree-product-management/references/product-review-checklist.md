- [ ] 背景与问题（业务触发、痛点）

- [ ] 依赖与风险

- [ ] 待确认事项

## 3. 问题分级

- **P0**：违反不变量 / 自相矛盾 / 关键状态缺失 / 安全漏洞 → 阻塞开发
- **P1**：验收模糊 / Contract 未对齐 / 状态机不完整 → 建议开发前解决
- **P2**：文案/埋点/可运营细节 → 可开发中确认
- **P3**：交互/辅助功能/视觉细化 → 后续版本

## 5. Contract 兼容检查

- [ ] 向前兼容：新 Contract 部署后旧客户端可用
- [ ] 向后兼容：旧 Contract 下新客户端可降级
- [ ] 未知事件/字段/Artifact 类型降级行为明确
- [ ] Idempotency Key 跨版本行为明确
- [ ] 新策略对运行中 Task 的影响明确

## 6. 开发准备度

- **READY**：无 P0/P1，范围/流程/状态/权限/验收明确
- **READY_WITH_OPEN_ITEMS**：存在 P2/P3 或 P1 已接受
- **NOT_READY**：存在 P0 或关键 P1 未关闭
